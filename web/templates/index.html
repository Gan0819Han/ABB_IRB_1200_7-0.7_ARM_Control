图表

三类图表任务共用同一组输出目录。核心图和工作空间图会同时用到图像目录与数据目录，避障图主要读取规划 JSON 并输出 PNG。

1. 核心图表

读取当前工程实验结果与单案例 JSON，生成论文主体中使用的性能图、误差图和汇总图。

2. 工作空间图

读取 `subspace_*_reference.npz` 等参考样本文件，生成工作空间三视图与三维分布图。

3. 避障图

基于规划结果 JSON 生成候选轨迹、碰撞对比与论文风格总览图，并在右侧结果栏显示最近 PNG。
